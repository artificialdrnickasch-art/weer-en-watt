Weer & Watt op YouTube

Nederlands

Weer & Watt is een Vlaams YouTube-kanaal van DrNickAsch over weer en energie: wekelijkse uitlegvideo's (zonnestroom, wind, goedkope uren bij een dynamisch tarief) en dagelijkse Shorts.

De Weer & Watt uploader is een klein, persoonlijk Python-script dat de YouTube Data API v3 (YouTube API Services) gebruikt om de eigen video's van dit kanaal te uploaden en in te plannen: titel, beschrijving, tags, privacystatus, publicatietijdstip, thumbnail en ondertitels. Het is geen publieke dienst: er zijn geen andere gebruikers, geen accounts om aan te maken en het script beheert uitsluitend het kanaal van de eigenaar.

English

Weer & Watt (“Weather & Watt”) is a Flemish YouTube channel by DrNickAsch about weather and energy: weekly explainer videos (solar output, wind, cheap hours on a dynamic electricity tariff) and daily Shorts.

The Weer & Watt uploader is a small, personal Python script that uses the YouTube Data API v3 (YouTube API Services) to upload and schedule this channel's own videos: title, description, tags, privacy status, scheduled publish time, thumbnail and captions. It is not a public service: there are no other users, no sign-ups, and the script only manages the owner's own channel.
