English

1. Who we are

This policy covers the “Weer & Watt uploader”, a personal API client operated by DrNickAsch for the YouTube channel Weer & Watt (Belgium). Contact: artificialdrnickasch@gmail.com.

2. Use of YouTube API Services

This API client uses YouTube API Services (the YouTube Data API v3). By using it, you agree to be bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy (http://www.google.com/policies/privacy).

3. Who uses it

The only user is the channel owner. The client is not offered to the public, has no sign-up and does not access any other person's Google or YouTube account.

4. What information is accessed

  • OAuth authorization: the owner signs in with Google once and grants the scopes youtube.upload and youtube.force-ssl. Google returns an access token and a refresh token.
  • YouTube API data of the owner's own channel: the channel ID and title, and the metadata and status of videos the client uploads (ID, title, description, tags, privacy status, scheduled publish time, processing status, thumbnails, caption tracks).
  • The client does not access viewers' data, comments, subscribers, analytics, e-mail, contacts or any other Google data, and does not collect information about visitors to this website.

5. How the information is used

Solely to upload the owner's own videos to the owner's own channel, set their metadata, thumbnails and captions, schedule their publication, and check that an upload or scheduled publication succeeded.

6. Storage

  • The OAuth token is stored only in a local file (token.json) on the private machine where the owner runs the script (the owner's own computer or a private cloud workspace used only by the owner), so the client can run without signing in each time.
  • No YouTube API data is stored in any database. Video IDs and statuses printed during a run may remain in local log files on that machine; these contain only the owner's own channel information.
  • No data is stored on this website. This website uses no cookies, analytics, trackers or advertising.

7. Sharing

Information is not sold, shared with or disclosed to any third party, internal or external, other than sending it to Google/YouTube through the API as needed to perform the upload. No third party serves content or advertisements in this API client.

8. Deletion and revoking access

  • Deleting the local token.json file removes all stored authorization data immediately. Any locally stored API data is deleted or refreshed within 30 days, as required by the YouTube API Services Developer Policies.
  • In addition to this, access can be revoked at any time via the Google security settings page: https://security.google.com/settings/security/permissions. After revocation the client can no longer access the account.
  • Videos uploaded to YouTube are managed and can be deleted in YouTube Studio.

9. Children

The client is not directed at children and is used only by the adult channel owner.

10. Changes and contact

Changes to this policy will be published on this page with a new date. Questions or complaints about these privacy practices: artificialdrnickasch@gmail.com. You may also contact the Belgian Data Protection Authority (gegevensbeschermingsautoriteit.be).

Nederlands

1. Wie zijn we

Dit beleid geldt voor de “Weer & Watt uploader”, een persoonlijke API-toepassing van DrNickAsch voor het YouTube-kanaal Weer & Watt (België). Contact: artificialdrnickasch@gmail.com.

2. Gebruik van YouTube API Services

Deze toepassing gebruikt YouTube API Services (de YouTube Data API v3). Wie ze gebruikt, gaat akkoord met de Servicevoorwaarden van YouTube. Hoe Google met gegevens omgaat, staat in het Privacybeleid van Google (http://www.google.com/policies/privacy).

3. Wie gebruikt de toepassing

De enige gebruiker is de eigenaar van het kanaal. De toepassing wordt niet publiek aangeboden, er is geen registratie en ze heeft geen toegang tot het Google- of YouTube-account van iemand anders.

4. Welke gegevens worden gebruikt

  • OAuth-toestemming: de eigenaar logt één keer in bij Google en geeft toestemming voor youtube.upload en youtube.force-ssl. Google geeft daarvoor een toegangs- en vernieuwingstoken.
  • YouTube-gegevens van het eigen kanaal: kanaal-ID en -naam, en de gegevens en status van de video's die de toepassing uploadt (ID, titel, beschrijving, tags, privacystatus, publicatietijdstip, verwerkingsstatus, thumbnails, ondertitels).
  • De toepassing gebruikt geen gegevens van kijkers, reacties, abonnees, statistieken, e-mail, contacten of andere Google-gegevens, en verzamelt niets over bezoekers van deze website.

5. Waarvoor

Uitsluitend om de eigen video's naar het eigen kanaal te uploaden, hun gegevens, thumbnails en ondertitels in te stellen, de publicatie in te plannen en te controleren of een upload of geplande publicatie gelukt is.

6. Bewaring

  • Het OAuth-token wordt alleen lokaal bewaard in een bestand (token.json) op de privé-machine waarop de eigenaar het script draait (zijn eigen computer of een privé-cloudwerkplek die alleen hij gebruikt).
  • Er worden geen YouTube-gegevens in een databank bewaard. Video-ID's en statussen kunnen in lokale logbestanden op die machine blijven staan; die bevatten alleen gegevens van het eigen kanaal.
  • Deze website bewaart geen gegevens en gebruikt geen cookies, statistieken, trackers of advertenties.

7. Delen

Gegevens worden niet verkocht en niet gedeeld met derden, intern of extern, behalve wat via de API naar Google/YouTube gaat om de upload uit te voeren. Er tonen geen derden inhoud of advertenties in deze toepassing.

8. Verwijderen en toegang intrekken

  • Wie het lokale bestand token.json wist, verwijdert meteen alle bewaarde toestemmingsgegevens. Lokaal bewaarde API-gegevens worden binnen 30 dagen gewist of vernieuwd, zoals de YouTube API Services Developer Policies vereisen.
  • Daarnaast kan de toegang altijd ingetrokken worden via de beveiligingsinstellingen van Google: https://security.google.com/settings/security/permissions.
  • Geüploade video's beheer of verwijder je in YouTube Studio.

9. Kinderen

De toepassing is niet bedoeld voor kinderen en wordt alleen door de volwassen kanaaleigenaar gebruikt.

10. Wijzigingen en contact

Wijzigingen verschijnen op deze pagina met een nieuwe datum. Vragen of klachten over dit privacybeleid: artificialdrnickasch@gmail.com. Je kan ook terecht bij de Belgische Gegevensbeschermingsautoriteit (gegevensbeschermingsautoriteit.be).
